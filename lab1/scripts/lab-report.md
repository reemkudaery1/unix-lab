# Shell Lab Report

## أهم الأوامر التي تم تنفيذها

- `pwd`: عرض المسار الحالي
- `mkdir -p`: إنشاء مجلدات متداخلة
- `cd`: التنقل بين المجلدات
- `ls`: عرض محتويات المجلد
- `touch`: إنشاء ملف فارغ
- `cp`: نسخ ملف
- `mv`: نقل أو إعادة تسمية ملف
- `echo`: طباعة نص
- `whoami`: عرض اسم المستخدم
- `date`: عرض التاريخ الحالي
- `chmod +x`: منح صلاحية التنفيذ لسكربت
- `./script.sh`: تنفيذ سكربت
- `git init`: بدء مستودع Git
- `git add .`: إضافة جميع الملفات
- `git commit -m "message"`: حفظ التغييرات
- `git log --oneline`: عرض سجل commits

## أسئلة التقييم

**1. ما الفرق بين `>` و `>>` و `&>`؟**

- `>`: إعادة توجيه المخرجات (يكتب من جديد، يحذف القديم)
- `>>`: إعادة توجيه مع الإلحاق (يضيف في نهاية الملف)
- `&>`: إعادة توجيه المخرجات والأخطاء معًا

**2. متى نستخدم `source` بدل `./script.sh`؟**

- `./script.sh`: ينفذ السكربت في عملية فرعية، فالتغييرات تضيع بعد الانتهاء
- `source script.sh`: ينفذ السكربت في نفس العملية، فتبقى التغييرات

**3. ما الفرق بين `&&` و `||`؟**

- `&&`: ينفذ الأمر الثاني فقط إذا نجح الأول
- `||`: ينفذ الأمر الثاني فقط إذا فشل الأول

**4. لماذا نستخدم الفروع (branches) في Git؟**

لعزل التطوير: نعمل على ميزة جديدة دون التأثير على النسخة المستقرة.

**5. ما وظيفة `ssh-agent`؟**

برنامج يدير مفاتيح SSH الخاصة في الذاكرة، لتجنب كتابة passphrase كل مرة.
